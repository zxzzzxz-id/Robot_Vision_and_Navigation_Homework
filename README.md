# 导航常用坐标系转换

## 1. 作业内容与课件依据

使用 Python 实现以下坐标系的双向转换：

1. WGS-84 椭球下的大地坐标 BLH 与空间直角坐标 XYZ；
2. 地球坐标系 XYZ / BLH 与当地地理坐标系 NEU；
3. 载体坐标系与地理坐标系 NEU。

主要使用第 2 章（Lecture 2）《导航相关时空基准》的知识：

| 转换内容 | 章节与页码 | 方法 |
|---|---|---|
| BLH ↔ XYZ | 第二节“导航相关的空间基准”，第 50–51 页 | 椭球坐标正算、纬度迭代反算 |
| XYZ / BLH ↔ NEU | 第三节“导航常用坐标系及转换”，第 74、89 页 | 坐标平移与方向余弦矩阵 |
| 载体系 ↔ NEU | 第三节，第 77–80、90 页 | Z-X-Y 欧拉角转换、矩阵转置 |

示例数据取自第 1 章（Lecture 1）第 47 页的武汉 IGS 站坐标。

## 2. 坐标约定

- BLH：纬度 B、经度 L、大地高 H；角度单位为度，位置单位为米。
- XYZ：WGS-84 地心地固坐标；NEU：北、东、天。
- 载体系：x 向右、y 向前、z 向上；零姿态时分别指向东、北、天。
- 姿态角：航向角 ψ 以北为零、顺时针为正；俯仰角 θ 抬头为正；横滚角 γ 右倾为正。

课件第 89 页的矩阵按东、北、天排列，程序交换前两行，统一为 NEU。载体系与 NEU 的向量转换采用同一原点。

## 3. 转换方法

### 3.1 BLH → XYZ

WGS-84 椭球参数及卯酉圈曲率半径：

```text
a = 6378137.0 m
f = 1 / 298.257223563
e² = f(2-f)
N = a / sqrt(1 - e²sin²B)
```

正算公式：

```text
X = (N + H)cosBcosL
Y = (N + H)cosBsinL
Z = [N(1-e²) + H]sinB
```

### 3.2 XYZ → BLH

经度由 `atan2` 计算，纬度迭代求解：

```text
p = sqrt(X² + Y²)
L = atan2(Y, X)
tan(B0) = Z / p
tan(Bi) = [Z + ae²tan(Bi-1) / sqrt(1 + (1-e²)tan²(Bi-1))] / p
H = p / cosB - N
```

相邻两次迭代值之差小于 `1e-12` 时停止，最多迭代 100 次。高纬度时用 `H = Z / sinB - N(1-e²)` 求高；极点经度约定为 0°。

### 3.3 XYZ / BLH ↔ NEU

以参考点的纬度 B₀、经度 L₀ 构造矩阵 C：

```text
C = [-sinB₀cosL₀, -sinB₀sinL₀, cosB₀]
    [-sinL₀,       cosL₀,       0    ]
    [ cosB₀cosL₀,  cosB₀sinL₀, sinB₀]

NEU = C(r - r₀)
r = r₀ + C^T NEU
```

r、r₀ 分别为目标点和参考点的 XYZ 坐标。BLH ↔ NEU 通过 XYZ 中转。

### 3.4 载体系 ↔ NEU

采用课件第 90 页的 Z-X-Y 顺序：偏航、俯仰、横滚。矩阵 A 将 ENU 分量转为载体系分量：

```text
A = Ry(γ) Rx(θ) Rz(ψ)

Ry = [ cosγ, 0, -sinγ ]    Rx = [ 1,  0,     0   ]
     [  0,   1,   0   ]         [ 0, cosθ,  sinθ ]
     [ sinγ, 0,  cosγ ]         [ 0, -sinθ, cosθ ]

Rz = [ cosψ, -sinψ, 0 ]    P = [ 0, 1, 0 ]
     [ sinψ,  cosψ, 0 ]        [ 1, 0, 0 ]
     [  0,     0,   1 ]        [ 0, 0, 1 ]

v_neu  = P A^T v_body
v_body = A P v_neu
```

P 用于交换东、北分量。
